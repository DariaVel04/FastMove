# FastMove

Find a Tampere sports facility that can fit the time you have free, including the journey there and back.

You choose a sport, a time window, how you travel, and a starting point. FastMove suggests places from the Liikkuva Tampere ticket and links you to [Timmi](https://timmi.tampere.fi/WebTimmi/#/) to check the real booking. The app is in English and Finnish.

The schedules and travel times in the app are examples, not live data. A green result means a possible match from that example data. Always check Timmi before you go.

Live app: [dariavel04.github.io/FastMove](https://dariavel04.github.io/FastMove/)

## Run it

```bash
npm install
npm run dev
```

Open the local address Vite prints.

## Check it

```bash
npm run check
npm run build
```
